# EU / USA 连通核心数据生成

2026-09-07，I16 数据准备完成。正式版本为 `connected-road-v2`，输出根目录 `data/road_connected_v2/`。18 组、180 批生成与独立校验全部通过，根目录 `status.json` 为 `completed`，总耗时 330.459 秒，生成任务已退出。旧随机采样数据保留；`road_connected_v1` 是保护 BFS 树的中间产物，不用于后续性能实验。

## 目的与边界

原 raw 50p 数据即使扫描所有源点，EU/USA 最大可达规模也只有 45/37 点，无法代表大规模路网 repair。改善连通性可建立有效工作负载，但不能推断运行时间一定下降，更不能把换数据后的差值算成算法加速。

`50p/75p/99p` 表示保留原图唯一无向边的比例；`10k/100k/1000k` 表示每批有向更新记录数。每组十批，每批严格 50% 删除、50% 插入。原始 Matrix Market 为 symmetric，生成器将每条无向边展开为两个方向，保留原始 1-based ID，不添加虚构道路。50p 边预算不足以连接原图所有顶点，因此选择大连通核心；核心外顶点不补边、不重编号。

## 算法

1. 规范化原始无向边，去重、去自环，构建 CSR。对各非孤立分量做 BFS，按分量大小降序、根 ID 升序排列，形成顶点序列。
2. 对每个保留比例，令边预算为 `B=floor(E*p/100)`，扫描 BFS 前缀。前缀内原图边数为 `E(k)`，连接该前缀所需森林边数为 `T(k)`。选择使 `min(B-T(k), E(k)-B)` 最大的前缀，并列时取较大的前缀。这样同时保留删除池与插入池容量，不需要逐图参数。
3. 打乱核心内边，使用并查集做随机顺序 Kruskal，得到永久保护森林。这不是均匀生成树采样。再从剩余边随机补足预算。BFS 仅用于选核心，不能直接保护源点 BFS 树，否则单位权最短距离会被固定。
4. 维护当前存在的非保护边池和当前不存在的核心边池。每批分别无放回采样 `scale/4` 条无向删除与插入，输出双向记录，再交换两池条目并打乱批内记录。单批没有无效删除、重复插入或增删抵消；跨批允许边重复出现，且严格依据当前状态判断合法性。
5. 三个规模共用同一初始图，通过硬链接节省空间。seed 默认 42，基础图和各规模使用确定性派生 seed；随机数用 `mt19937_64` 和拒绝采样，避免标准库分布实现差异。

复杂度：规范化排序 `O(E log E)`，CSR/BFS/前缀扫描 `O(V+E)`，每个比例随机森林构造约 `O(E_core alpha(V_core))`，每批采样与输出 `O(scale)`，内存 `O(V+E+scale)`。没有反复检测删边是否为桥，也没有逐更新全图遍历。

**采样偏差必须保留在实验说明中**：删除仅覆盖非保护边，并非对所有现存边均匀删除；森林边不会删除，插入只使用原图核心内缺失的道路。保护随机森林避免了固定最短路径树，但仍会改变删除难度。实际 affected、边访问和 repair 轮数须另行运行 I16 测量，连通性校验不等于 SSSP runtime 验收。

## 使用

统一入口同时支持 EU 与 USA，无需维护两份生成逻辑：

```bash
python3 scripts/generate_connected_road_datasets.py
```

复现实验时使用新的空目录；已有非空目录会被拒绝，避免覆盖：

```bash
python3 scripts/generate_connected_road_datasets.py --output-root data/road_connected_replay
python3 scripts/generate_connected_road_datasets.py --dataset usa --output-root data/usa_connected_replay
```

要求 Python 3、支持 C++17 的 g++、仓库 `deps/json`，以及支持硬链接的输出文件系统。默认 EU 源为 `../DataSet/europe_osm/europe_osm.mtx`，USA 源为 `data/road_usa/road_usa.mtx`，可通过 `--eu-source/--usa-source` 指定。生成与校验仅使用 CPU。

路径模板：`data/road_connected_v2/{europe_osm,road_usa}/{50p,75p,99p}/`。例如 EU 50p 100k 的三文件为：

```text
input_europe_osm_50p_100k.txt
update_europe_osm_50p_100k.txt
stream_size_europe_osm_50p_100k.txt
```

输入为无头两列有向边表，更新为 `a/d u v 1`，批大小文件每行 `adds deletes`，适用现有 `market_big` 输入路径。**六种基础图都使用 `--source_node=1`**；source=0 不在原始 ID 范围。不要让旧 I16 runner 默认路径自动指向新数据，须建立独立 cohort。

## 校验与证据

独立 C++ verifier 重新读取输出，检查保护森林无环且完整保留、双向唯一边、所有批次真实增删与平衡计数、更新端点留在保护分量内。由于整个删除过程中森林不变，可证明 deletion-only 中间态和最终态的分量连通性保持。它不读取原始 Matrix Market 逐边做全集成员审计；生成器只从规范化原图 edge ID 池输出，小图回归另行检查输出全部属于原图。

每个图包含 `metadata.json`、`verification.json`、`checksums.json`；根目录包含 `status.json`、`manifest.json`、生成/校验日志和 `_tools/` 下冻结的源码与二进制。manifest 记录原始输入 SHA-256、工具 hash 和参数；checksums 记录生成文件 SHA-256。校验和完成后才把暂存目录发布为正式目录。复制数据时保留硬链接，否则 verifier 的跨规模同图身份检查会拒绝复制品。

回归：`tests/connected_road_generator_test.py` 覆盖三个比例十批、连通中间态、真实距离变化、原图边成员关系、确定性、损坏更新拒绝和不足边预算拒绝。

## 实际规模

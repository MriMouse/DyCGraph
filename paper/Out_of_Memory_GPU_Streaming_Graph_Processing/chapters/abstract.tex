Streaming graph processing is essential for applications such as fraud detection and network monitoring, where relationships evolve continuously. When graphs exceed GPU memory, maintaining topology and updating analytical results efficiently requires minimizing redundant computation and CPU--GPU data movement. We present CoIncGraph, a CPU--GPU cooperative system for incremental processing of out-of-memory streaming graphs. First, a heterogeneous source-isolated graph organization exploits topological locality through independently allocated adjacency blocks and a unified change view, limiting data movement and GPU index maintenance to changed sources. Second, CPU--GPU collaborative compact incremental computation improves concurrency by overlapping CPU preparation of affected incoming adjacency with GPU deletion repair, restricting computation and data transfers to affected vertices. Third, workload-specific optimizations complete deletion repair before insertion processing, seed propagation only from vertices improved by inserted edges, and construct compact worklists as improvements propagate, avoiding graph-wide worklist construction and unnecessary adjacency traversal. Extensive experiments show that CoIncGraph outperforms Ingress, SHGraph, and Grapin across CPU-based, GPU in-memory, and CPU--GPU out-of-memory graph processing, respectively.  %最后一句后面还需要加上对应的加速比情况，后面再修改
